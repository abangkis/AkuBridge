    Windows security notice

    The current testing installer and native runtime are not code-signed yet. Windows Security, Avast, or another antivirus may warn, quarantine, block, or sandbox them. Verify that the download came from the official AkuBrowser GitHub release before allowing it. Do not disable antivirus protection or exclude your Downloads folder.

    Avast CyberCapture may open this unsigned installer twice, including a second Setup window that appears after the first installation finishes. Complete only the first Setup window. If another appears, select No or Cancel; do not run Repair twice.

    If installation or Update now fails with Access is denied, restore any quarantined AkuBrowser file and add a narrow exception for %LOCALAPPDATA%\Programs\AkuBrowser\. Stop the running AkuSidecar.exe, then return here and select the available runtime action.

Version conflict

Stop the older portable runtime?

The portable runtime is unmanaged, so AkuBrowser cannot stop it securely from Chrome. Close it manually before starting the installed runtime.

Runtime to close AkuBrowser Portable Runtime Task Manager → Details process: AkuSidecar.exe
  1. Close the terminal or window that launched the portable AkuBrowser bundle.
  2. If that window is no longer visible, open Task Manager → Details and end AkuSidecar.exe from the extracted AkuBrowser bundle. Do not end AkuBrowserRuntimeHost.exe.
  3. Select I've stopped it — check again.
