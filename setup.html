Siapkan feed AI pribadi Anda

Memeriksa komponen AkuBrowser di komputer ini...

Extension Chrome sudah terpasang. Runtime lokal diperlukan agar AkuBrowser dapat berjalan di komputer Anda.

Installer Windows berjalan untuk pengguna saat ini dan tidak menghapus data AkuBrowser ketika diperbaiki atau dihapus.

Privasi & persetujuan

Pilih sumber yang boleh dibaca

AkuBrowser membaca konten feed yang dirender, nama akun, URL posting, waktu, dan media hanya dari sumber yang Anda aktifkan. Data dipakai untuk membuat dan mempersonalisasi feed AkuBrowser. Data disimpan oleh runtime di perangkat ini dan tidak dijual atau dipakai untuk iklan.

Saat fitur AI dijalankan, runtime dapat mengirim konten terpilih ke OpenAI melalui Codex App yang Anda gunakan. AkuBrowser tidak meminta password atau cookie akun sosial Anda.

Sumber opsional

Dengan menekan tombol di bawah, saya memberi izin untuk membaca sumber yang saya pilih sesuai penjelasan di atas. Izin dapat dicabut kapan saja.

Kebijakan privasi

Belum ada sumber sosial yang diizinkan.
